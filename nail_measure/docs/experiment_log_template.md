# 실험 기록 템플릿

카메라 높이별 정확도 실험을 진행할 때, `height_experiment.py log` 명령으로
자동 기록되는 내용 외에 사람이 직접 참고할 메모용 템플릿이다.
실험 하나(사진 한 장 + 측정 + 비교)를 마칠 때마다 아래 표를 한 줄씩 채워서
`docs/` 폴더에 함께 보관하면, 나중에 `experiment_log.csv` /
`measurements.csv` / `comparison.csv`만 봐서는 알기 어려운 상황(예: 손이
흔들렸다, 조명을 중간에 바꿨다 등)을 기록해둘 수 있다.

## 실험 기본 정보

| 항목 | 값 |
| --- | --- |
| 실험 날짜 | YYYY-MM-DD |
| 카메라 모델 | 예: Arducam 16MP AF |
| 카메라 높이(cm) | 예: 20 |
| 해상도 | 예: 1920x1080 |
| 조명 조건 | 예: 책상 스탠드 + 자연광 |
| 초점 방식 | 예: auto / fixed |
| 이미지 파일 경로 | data/captured/xxxx.jpg |
| 보정 JSON 경로 | data/results/xxxx_calib.json |
| px_per_mm | 예: 48.0 |

## 비고 / 특이사항

- 예: 셋째 손가락 촬영 시 그림자가 져서 뿌리 위치 클릭이 애매했음
