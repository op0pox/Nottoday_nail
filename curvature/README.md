# Nottoday_nail — 네일 팁 곡면 계산기

손톱의 **정면 너비**와 **측면 너비** 두 가지 실측값과 **곡면 유형(P/B/S/C)** 을 입력하면,
네일 팁 제작에 필요한 **곡면 길이**를 계산하는 도구입니다.

## 계산 원리

유형에 관계없이 계산 흐름은 동일하고, 유형별 비율(`k_a`, `k_h`, `k_f`)만 다릅니다.

```
a = k_a × 정면너비        측정 삼각형의 밑변
b = 측면너비              측정 삼각형의 높이 (실측값 그대로)
c = √(a² + b²)            측정 삼각형의 빗변 = 원호 계산용 현(chord)

h = k_h × c                현 c 에 대한 새그(sag)
r = c²/(8h) + h/2          곡률 반지름
θ = 2·arcsin(c/2 ÷ r)      중심각
L = r·θ                    편측 원호 길이

곡면 길이 = 2L + k_f × a    최종 결과값 (좌우 원호 2개 + 상단 평탄부)
```

### 유형별 비율

| 유형 | k_a (a = k_a×정면너비) | k_h (h = k_h×c) | k_f (곡면길이 = 2L+k_f·a) |
|------|------|------|------|
| **P형** (평행) | 2/5 | 1/4 | 1/2 |
| **B형** (버드) | 3/8 | 1/6 | 2/3 |
| **S형** (부채) | 3/7 | 1/7 | 1/3 |
| **C형** (평행) | 3/7 | 1/5 | 1/3 |

각 유형의 공식은 `P형/B형/S형/C형 계산.pdf` (프로젝트 루트) 도식을 그대로 코드로 옮긴 것입니다.

**예시** — P형, `정면너비=14mm, 측면너비=6mm` 인 경우:

| 항목 | 값 |
|------|-----|
| a / b / c | 5.60 / 6.00 / 8.21 mm |
| 새그 h | 2.05 mm |
| 곡률 반지름 r | 5.13 mm |
| 중심각 θ | 106.3° |
| 편측 호 길이 L | 9.51 mm |
| **곡면 길이** | **21.83 mm** |

## 주요 기능

- **유형 선택** — P / B / S / C 세그먼트 버튼으로 즉시 전환
- **실시간 계산** — 값을 입력하면 자동으로 재계산 (버튼 불필요)
- **3단 계산 도식** — ① 측정 삼각형(a·b·c) ② 원호 계산(r·θ·L) ③ 유형별 최종 전개도(2L+k_f·a)
- **보조 지표** — a, b, c, h, r, θ, L(편측 호), 평탄부 길이
- **편의 기능** — ±스테퍼/방향키로 미세조정(0.5mm 단위), 결과값 클립보드 복사

## 다른 모듈에서 사용하기

계산 로직은 GUI와 분리되어 있어 함수 하나로 가져다 쓸 수 있습니다:

```python
from curvature import calc

result = calc("P", front_width=14.0, side_width=6.0)   # 유형: "P" | "B" | "S" | "C", 단위: mm
print(result["total"])   # 최종 곡면 길이 (mm)
# 반환 키: category, name, front_width, side_width,
#          a, b, c, h, r, theta_deg, L, flat, total,
#          k_a_s, k_h_s, k_f_s (공식 표시용 비율 문자열)
```

## 모델의 가정

- 손톱 정면 단면은 **상단 평탄부 + 좌우 대칭 원호 2개**로 구성된다고 가정합니다.
- 평탄부와 원호의 비율(k_a, k_h, k_f)은 유형(P/B/S/C)마다 고정된 경험적 비율을 사용합니다.
- 원호 1개는 현(c)·새그(h) 기반의 단일 원호(새그 공식)로 근사합니다.
