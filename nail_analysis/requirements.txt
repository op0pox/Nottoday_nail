# ChArUco(cv2.aruco) 캘리브레이션/스케일 계산에 cv2.aruco 모듈이 필요하다.
#
# [Jetson Nano] JetPack 기본 OpenCV(APT로 깔린 libopencv-python 등)에는 보통
# GStreamer(CSI 카메라)와 aruco가 이미 포함되어 있다. 아래 opencv-contrib-python을
# pip으로 새로 설치하면 GStreamer 지원이 빠진 버전으로 덮어써서 camera.py의
# CSI 카메라 열기가 실패할 수 있다 - 아래 확인 명령으로 먼저 점검할 것.
#
#   python3 -c "import cv2; print(cv2.getBuildInformation())" | grep -i gstreamer
#   python3 -c "import cv2; print(hasattr(cv2, 'aruco'))"
#
# 위 두 확인이 모두 정상(GStreamer YES, aruco True)이면 아래 줄은 설치하지 말 것.
# 시스템 OpenCV에 aruco가 없을 때만 주석을 해제한다(GStreamer 지원이 빠질 수 있음에 주의).
# opencv-contrib-python>=4.7.0

# [노트북/PC, 카메라 없이 --front-image/--side-image/--images로 정지 이미지 모드만
