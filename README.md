# Nottoday_nail — 네일 팁 곡면 계산기

손톱의 **너비(w)** 와 **높이(h)** 두 가지 실측값만으로 네일 팁 제작에 필요한 **곡면 길이(L)** 를 계산하는 도구입니다.
손톱 단면을 단일 원호(N형)로 모델링하여 곡률 반지름, 호의 각도, 펼친 길이를 구합니다.

## 계산 원리

손톱 단면이 `(0,0) → (w/2, h) → (w,0)` 세 점을 지나는 원호라고 가정하면:

```
R = w²/(8h) + h/2        # 곡률 반지름 (새그 공식)
θ = 2·arcsin(w/2 ÷ R)    # 호의 중심각
L = R·θ                  # 곡면 길이 (호의 길이)
```

`L`은 손톱을 평평하게 폈을 때의 실제 단면 길이로, 네일 팁 제작 시 필요한 폭에 해당합니다.

**예시** — `w=14mm, h=2mm` 인 경우:

| 항목 | 값 |
|------|-----|
| 곡률 반지름 R | 13.25 mm |
| 호의 각도 θ | 63.8° |
| C커브 | 18 % |
| **곡면 길이 L** | **14.75 mm** |

## 주요 기능

- **실시간 계산** — 값을 입력하면 자동으로 재계산 (버튼 불필요)
- **3D 미리보기** — 계산된 곡면을 입체로 렌더링
- **단면도** — 실제 비율의 단면과 "펼친 길이 L" 비교 바 표시
- **보조 지표** — 곡률 반지름 R, 호의 각도 θ, C커브(%), 현 길이
- **편의 기능** — ±스테퍼/방향키로 미세조정(w: 0.5mm, h: 0.1mm), 결과값 클립보드 복사

## 다른 모듈에서 사용하기

계산 로직은 GUI와 분리되어 있어 함수 하나로 가져다 쓸 수 있습니다:

```python
from curvature import calc

result = calc(w=14.0, h=2.0)   # 단위: mm
print(result["L"])              # 곡면 길이 (mm)
# 반환 키: chord, h, R, theta_deg, L
```

## 모델의 가정

- 손톱 단면 전체가 곡률이 일정한 **하나의 원호**(N형)라고 가정합니다.
- 최고점이 너비의 정중앙(w/2)에 있는 **좌우 대칭** 형태를 가정합니다.
